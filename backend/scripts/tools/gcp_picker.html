실내 도면
사용 방법
  1. 상단에 VWorld 인증키를 붙여넣고 Apply
  2. 왼쪽 지도에서 더현대 서울로 이동, 최대 줌
  3. "다음 GCP 이름" 칸에 라벨(예: NE-corner) 입력
  4. 왼쪽에서 그 지점을 클릭 → 야외 lat/lng 저장
  5. 필요하면 오른쪽에 실내 도면 이미지 업로드
  6. 같은 라벨을 유지한 채 오른쪽에서 같은 지점을 클릭 → 실내 픽셀 저장
  7. 라벨을 바꿔가며 4~6개 반복 → Export JSON
