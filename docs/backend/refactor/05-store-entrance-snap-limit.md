# 05. 매장 입구 스냅 거리 제한과 unresolved 보고

브랜치(제안): `fix/store-entrance-snap-limit`

## 배경

매장 입구를 가장 가까운 그래프 노드에 연결할 때 최대 거리 제한이 없으면, 잘못된 원본 좌표가 벽 반대편 복도나
건물 반대편 노드에 강제로 연결될 수 있다. 이 경우 매장 polygon을 가로지르는 경로나 실제로는 접근 불가능한
출입구가 생성된다.

## 범위(백엔드만)

Studio 시드 어댑터의 매장 입구 연결 로직.

## 작업 항목

1. 매장 입구를 그래프 노드에 스냅할 때 최대 거리를 설정한다(건물별로 다를 수 있으면 설정값으로 노출).
2. polygon 경계와 복도 geometry 관계를 검사한다(입구가 실제로 복도 쪽을 향하는지).
3. 임계값을 초과하면 자동 연결을 금지하고 `unresolved_store_entrance`로 보고한다.
4. unresolved 항목을 JSON artifact로 저장한다(03번 validator의 출력 형식과 통일).
5. 건물별 unresolved 허용 기준(0건이어야 하는지, 일부 허용인지)을 설정한다.
6. 임계값 근처 항목을 사람이 검수할 수 있는 시각화(간단한 GeoJSON 또는 이미지)를 생성한다 — 기존 시드 검증 리포트에 추가.

## 완료 기준

- [x] 최대 거리를 벗어난 입구는 그래프에 자동 연결되지 않는다. — `_reshape_stores`가 스냅 거리 > `settings.store_entrance_snap_max_m`이면 `entrance_node_id`를 비운다.
- [x] 매장 입구 검증 결과가 시드 보고서에 포함된다. — `reset_and_seed`가 `data/seed_graph_report.json`의 `store_entrances`에 미연결 목록·수를 남긴다.
- [x] 연결되지 않은 입구로 인해 잘못된 경로가 생성되지 않는다(회귀 테스트로 확인). — 연결된 입구가 모두 임계값 안의 노드를 가리키고, 미연결이 그래프 무결성을 깨지 않음을 실데이터로 검증(`tests/integration/test_store_entrance_snap_seed.py`).

## 설계 결정

- **임계값 기본 25m(설정으로 노출).** 실데이터 스냅 거리 분포를 측정해 정했다 — 정상 입구도
  가장 가까운 junction까지 대부분 6~10m(p50 6.7m, p90 9.3m, p99 17.8m)라 낮게 잡으면 정상
  매장이 대량 미연결된다. 25m를 넘는 것은 12개 층 전체에서 9건(≈0.5%)뿐이고, 대부분
  출입구·승강기·게이트 같은 구조물이라 라우팅 목적지가 아니다. 건물 특성이 다르면
  `NAV_STORE_ENTRANCE_SNAP_MAX_M`로 조정한다.
- **미연결은 시드를 막지 않는다(경고성).** 그래프 무결성 에러(타 건물 연결 등)는 시드 게이트가
  롤백하지만, 먼 입구는 매장 자체를 지우지 않고(지도에는 그대로 보임) 경로 도착점만 비운 채
  리포트에 남긴다 — "일부 허용, 검수 대상"이다.

## 남은 작업(범위 밖)

- **polygon–복도 geometry 관계 검사(원 item 2).** 입구가 실제로 복도 쪽을 향하는지 폴리곤
  경계로 확인하는 것은 거리 제한보다 복잡하고 오탐이 많다. 주된 실패 모드(먼 오연결)는 거리
  제한으로 이미 잡히므로 분리한다.
- **임계값 근처 항목 시각화(원 item 6).** GeoJSON/이미지 검수 도구는 별도 작업으로 둔다. 현재는
  `seed_graph_report.json`의 `store_entrances`에 거리·사유를 남겨 검수 근거를 제공한다.
