# 04. 수직 이동 간선 생성 알고리즘 결정성 확보

브랜치(제안): `fix/vertical-edge-generation-determinism`

## 배경

위치 기반 에스컬레이터 매칭이 가장 가까운 미사용 노드를 순차 선택하는 방식이면, 후보가 비슷할 때 입력 순서에
따라 결과가 달라질 수 있다. 엘리베이터 샤프트 그룹핑도 첫 대표 좌표 기준 탐욕적 구성이면 같은 샤프트가
여러 그룹으로 쪼개지거나, 가까운 다른 샤프트와 잘못 병합되거나, 한 샤프트의 모든 층 쌍을 연결해 간선 수가
`O(F²)`로 증가하는 문제가 있다.

## 범위(백엔드만)

Studio 시드 어댑터의 수직 전이 생성 로직(`backend/scripts/seed/studio_adapter.py` 등).

## 작업 항목

1. 입력을 층 level과 node ID 기준으로 안정 정렬(stable sort)한 뒤 매칭을 수행한다.
2. 근접 매칭에 bipartite minimum-cost matching을 적용해 순차 탐욕 선택을 대체한다.
3. 엘리베이터 샤프트 그룹핑에 DBSCAN 또는 union-find 기반 군집화를 적용한다.
4. 이름·위치·원본 topology가 충돌하면 자동으로 하나를 선택해 연결하지 않고, 검증 오류 또는 사람이 확인할
   override 대상으로 분리한다(03번에서 만든 validator의 unresolved 항목으로 보고).
5. 동일 입력의 permutation(순서만 바꾼 입력)에서 결과가 동일한지 확인하는 property test를 추가한다.
6. 엘리베이터 간선 수를 줄이기 위해 "각 층 엘리베이터 노드 ↔ 엘리베이터 샤프트 hub" 가상 hub node 도입을 검토한다 — 샤프트당 간선을 `O(F²)`에서 `O(F)`로 줄인다.

## 완료 기준

- [ ] 입력 순서를 바꿔도 생성 결과(간선 집합)가 동일하다.
- [ ] 샤프트별 간선 수가 층 수에 선형으로 증가한다(`O(F)`).
- [ ] 동일 샤프트/인접 샤프트 분류에 대한 테스트가 통과한다.
- [ ] 원본 topology와 충돌하는 위치 기반 폴백이 자동으로 적용되지 않는다.
